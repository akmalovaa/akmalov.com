# Windows

Подборка программ, которые удобно установить после переустановки Windows. Ссылки ведут на официальные сайты и страницы проектов.

## Основные приложения

- [Google Chrome](https://www.google.com/chrome/) — браузер.
- [Telegram](https://desktop.telegram.org/) — мессенджер.
- [Obsidian](https://obsidian.md/) — заметки в Markdown и личная база знаний.
- [NetBird](https://netbird.io/) — подключение устройств к частной сети; нужен, если используешь NetBird.

## Разработка

Устанавливаю по задачам: для редактирования файлов достаточно редактора, а Python и Node.js нужны для соответствующих проектов.

- [Visual Studio Code](https://code.visualstudio.com/) — редактор кода.
- [MobaXterm](https://mobaxterm.mobatek.net/) — терминал с SSH и передачей файлов по SFTP.
- [Git](https://git-scm.com/downloads) — управление версиями и работа с репозиториями.
- [Python](https://www.python.org/) — интерпретатор для скриптов и Python-проектов.
- [uv](https://docs.astral.sh/uv/getting-started/installation/) — управление версиями Python, зависимостями и окружениями. При использовании uv отдельная установка Python часто не нужна.
- [Node.js](https://nodejs.org/en/download) — среда выполнения JavaScript и инструменты для веб-разработки.

## Системные утилиты

- [FreeFileSync](https://freefilesync.org/) — сравнение и синхронизация папок.
- [TreeSize Free](https://www.jam-software.com/treesize_free) — поиск папок и файлов, занимающих место на диске.
- [PowerToys](https://github.com/microsoft/PowerToys) — набор дополнительных инструментов Windows, в том числе для настройки клавиатуры и размещения окон.

### Сочетания клавиш как на Mac

В PowerToys открыть **Keyboard Manager → Remap a shortcut** и добавить нужные сочетания. Например, `Alt + C` → `Ctrl + C` и `Alt + V` → `Ctrl + V`: копирование и вставка будут на позиции, привычной для `Command` на клавиатуре Mac.

Такие переназначения заменяют исходные действия `Alt + C` и `Alt + V`. При необходимости ограничить их конкретным приложением. PowerToys должен работать в фоне.

Подробнее — в [документации Keyboard Manager](https://learn.microsoft.com/en-us/windows/powertoys/keyboard-manager).
